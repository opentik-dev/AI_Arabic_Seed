# Corpus

هذا المجلد هو مصدر الحقيقة لبيانات التدريب.

قبل التوسع:
1. احتفظ بمصدر كل مجموعة بيانات وترخيصها.
2. افصل البيانات الخام عن البيانات المنظفة.
3. سجّل الإصدار والتاريخ وعدد الأحرف/الرموز.
4. أزل التكرار والصفحات المزعجة والـ boilerplate.
5. لا تخلط بيانات الاختبار في corpus التدريب.

`corpus.txt` المرفق صغير جدًا؛ هو smoke test وليس corpus تدريب لغوي حقيقي.
